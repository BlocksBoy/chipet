# Chipet（芯宠）设计文档

> 日期：2026-11-15  
> 状态：第 1 周进行中（合约 + 本地可玩前端 + 广场社交 + 通电玩耍 / 电路对战 / 牵线合体的本地版已落地，见 §13）  
> 参赛：X Layer TapeOut Accelerate（截止 2026-12-07 23:59 UTC）

## 1. 一句话

链上电子宠物：每只宠是一枚 TapeOut 电路 NFT。平时喂养、变帅；对战结果由电路在链上 `eval` 判定。点「基因」才看到芯片版图——大众玩法，TapeOut 是隐藏设定。

## 2. 决策摘要

| 问题 | 选择 |
|---|---|
| 产品形态 | 养成 + 轻对战宠物 |
| 开局体验 | 孵化开箱 → 起名 → 喂一口（收藏感） |
| 电路可见性 | 玩法里直接可见（通电、对战、合体都展示电路求值），用「心脏 / 引脚 / 亮灯 / 功率」这类口语，不要求玩家懂 NAND |
| 日常循环 | 喂养成长 + 偶尔打野怪 / 好友 |
| 与 TapeArena | Chipet 成主提交；TapeArena 降为底层判题库，擂台不主推 |
| 名字 | Chipet / 芯宠（可改） |

## 3. 要解决的问题

对手多在做「打开就能玩」的社交、一键建站、小游戏；TapeArena 技术深但用户窄。Chipet 用同一套 TapeOut 能力，把门槛降到「养电子宠物」，同时保留链上可验证对战，满足评审的用户价值、创新、生态应用、体验四条。

## 4. 核心循环

### 4.1 第一个 60 秒

连钱包（或安装引导）→ 付孵化费 → 开箱动画 → 随机初阶宠 → 起名 → idle 动画 → 喂一口 → 点一次「基因」看芯片彩蛋 → 提示明天再喂或去训练场。

### 4.2 日常

1. **养成**：喂食 / 玩耍（冷却），影响能量、心情、亲密度、外形档位。  
2. **轻对战**：选招 vs 野怪或好友；合约对双方电路 `eval` 定胜负。  
3. **收集**：物种 / 稀有度图鉴。

### 4.3 MVP 不做

开放世界、自由繁殖树、玩家手写电路、复杂技能树、Token 盘、重度好友赌金。

## 5. 电路 ↔ 宠物

- 每只宠绑定 `cpu` + `circuitId`（TapeOut 电路 NFT）。  
- 玩家不写网表；孵化从预置模板池抽取（普通 / 稀有 / 传说）。  
- **外形**：对电路做固定输入 `eval` → 比特指纹 → 映射物种、配色、花纹、饰品、idle。同电路同外形。  
- **养成数值**：能量、心情、亲密度、等级。等级只加体力等修正，**不改电路**。  
- **基因页**：版图缩略、门数、稀有度、通俗文案（「这只狐狸的心脏是 42 门加法器」）、电路 ID。

## 6. 对战

每回合：选招（进攻 / 防御 / 技巧）→ 映射为电路输入位 → 混入 `blockPrevRandao`（或后续 VRF）→ 双方 `eval` → 比输出定扣血 / 胜负。  
野怪 = 官方预置电路 + 等级修正。  
Gas 策略：Demo 优先小电路全链上；若 gas 紧，野怪战可做乐观提交，但 Demo 至少展示一次真实 `eval`。

## 7. 合约

| 合约 | 职责 |
|---|---|
| `ChipetHatchery` | 收孵化费、模板池、mint 宠并绑定电路 |
| `ChipetPet`（ERC-721） | 名字、绑定、能量/心情/等级、喂食冷却 |
| `ChipetArena` | 野怪 / 好友战：招式 → 随机 → `eval` → 结算 |

预置 8～12 枚模板电路（部署前 tapeout），地址写入 Hatchery。

## 8. 前端页面

1. 首页 / 孵化  
2. 我的芯宠（喂食、玩耍、基因）  
3. 训练场（野怪战）  
4. 图鉴  

复用：钱包、Tailwind、`@tapearena/netlist`、链封装、DeWEB 发布。TapeArena 擂台路由隐藏或放入「实验室」。

## 9. 收入叙事（交表单）

孵化费、饲料小额 OKB、后期皮肤 / 门票；协议抽成。留存：养成习惯 + 图鉴 + 轻对战。

## 10. 里程碑（至 12-07）

**第 1 周**  
宠物 NFT + 孵化开箱 + 外形指纹 + 喂食 + 基因页骨架。

**第 2 周**  
Arena `eval` 对战 + 打磨动画 / 文案 + DeWEB + Demo 视频 + 更新参赛说明。

**Demo 必拍**  
孵化 → 喂一次 → 基因页 → 打赢野怪 → 升级；至少一次链上 `eval`。

## 11. 风险

- `eval` gas 与回合复杂度  
- 与「咖啡馆小游戏」差异要讲清：基因=电路、胜负可验证  
- 时间紧：垂直切片优先于功能宽度  

## 12. 开放项

- 中英文最终品牌名  
- 物种美术风格（像素 / 矢量扁平）  
- 好友战是否上线 MVP  
- TapeArena 代码保留程度（仅库 vs 实验室入口）

## 13. 互动与社交扩展（本地演示版）

目标：让 TapeOut 电路从「基因页彩蛋」变成每个玩法的核心，同时保持大众可玩。全部在浏览器里用 `@tapearena/netlist` 的 VM 逐门求值，尚未上链。

- **心脏电路**：每只宠按稀有度从 11 枚模板里取一枚真实网表（`web/src/chipet/heart.ts`）。普通 9–26 门，珍奇 12–18 门，限定 36–45 门。
- **通电玩耍**（替代原「玩耍」按钮）：拨输入引脚，让输出灯与目标一致，共 3 关，按拨动次数给星；结算心情、经验，满星送鱼干。
- **电路对战**（训练场）：每回合由种子 + 回合 + 招式派生输入位，电路输出亮灯数换算功率 1–4；进攻 > 技巧 > 防御 > 进攻，克制方伤害翻倍、被克方减半。对手有野怪（5 只芯片 Bug）和邻居芯宠。每场耗 15 能量，胜负给经验，可升级。
- **牵线 / 合体技**：和邻居芯宠牵线（1 鱼干，最多 3 根），两颗心脏用 REF 串成一枚合体电路；对战中每场可放一次，无视克制。
- **社交补充**：今日任务（4 项，各奖 1 鱼干）、动态击掌、对战胜场榜、邻居回访与切磋留言。邻居仍是本地 NPC。

上链时要替换的部分：随机位改用 `blockPrevRandao`，求值改由 `ChipetArena` 调 `eval`，牵线改为真实流片一枚含 REF 的电路。

## 14. 多网络与中英文

**网络**：页头可选 X Layer（196）和 BSC（56），选择记在 `localStorage['tapearena.chain']`。链配置在 `packages/chain/src/networks.ts`（`CHAINS` / `MAINNET_IDS` / `CHAIN_LABEL`），前端可选列表在 `web/src/env.ts` 的 `CHAIN_IDS`。本地 fork 只在有部署记录时出现；DeWEB 构建只连 X Layer。币种符号取当前链的 `nativeCurrency.symbol`（OKB / BNB）。

- 两条主网上都还没有部署 Chipet 合约，现在都走本地演示模式；首页会写明是哪条链没部署。
- TapeOut 官方工厂只在 X Layer 上。`DeployChipet.s.sol` 在 X Layer / 本地 fork 上默认用官方工厂，其他链必须用环境变量 `TAPEOUT_FACTORY` 指定，否则直接报错。

**语言**：页头「中 / EN」切换，记在 `localStorage['chipet.lang']`，没选过时按浏览器语言。

- 不建 key 表，文案就地写成 `t('中文', 'English')`。当前语言的唯一来源是 `packages/netlist/src/locale.ts`，所以编译器报错、链上步骤提示也跟着切换；`web/src/i18n.ts` 在它上面加了 React 订阅（`useT` / `useLang`）。
- 只构建一次的数据（心脏、招式、野怪、物种、任务、邻居）用 getter 取文案，切语言不用重新挂载页面，进行中的对战和关卡不会丢。
- 存进 localStorage 的社交文本（动态、留言、气泡）存成 `{ zh, en }`；加双语之前的老记录是纯字符串，预置内容和孵化动态会补上英文，其余原样显示。
- 英文文案只用 ASCII 直引号：正文字体是 Noto Sans SC，弯引号会被渲染成全角。
- 后端（`server/`）的报错和 AI 助手的反馈仍是中文。
