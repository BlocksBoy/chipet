# Demo 视频脚本（2 分 50 秒）

录制前准备：

1. 本地起 X Layer 主网 fork 并灌入演示数据（6 个擂台、作弊被挑战、分润结算）：
   ```bash
   anvil --fork-url https://rpc.xlayer.tech --chain-id 31337 --port 8545
   echo '{}' > packages/chain/src/deployments.json   # 每次新开 anvil 都要清空
   npx tsx scripts/demo.ts
   npm run dev -w server   # 只有录 AI 片段才需要，并配置 AI_API_KEY
   npm run dev -w web      # http://localhost:5288
   ```
   主网部署好以后，也可以直接录主网 / 链上网站版本。
2. 浏览器右上角选「本地 fork」网络，缩放 90%，关闭无关标签。
3. 录屏 1920×1080，配音按下面的旁白读，字幕同旁白。

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0:00–0:15 | 首页大标题 + 右侧芯片版图的信号流动画 | TapeOut 让任何人都能在 X Layer 上造芯片。可造好的电路给谁用？谁来付钱？TapeArena 把它变成一个擂台。 |
| 0:15–0:35 | 往下滚到擂台列表，鼠标停在 8 位加法器擂台的卡片上 | 出题人托管奖金、写明引脚和测试向量。设计者提交自己流片的电路，合约当场调用 TapeOut 的 eval 跑完全部向量，按 NAND 门数排名，最少门数的正确电路赢。没有任何链下裁判。 |
| 0:35–1:00 | 点进 #2 八位加法器：排行榜里 bob 72 门第一、erin 86 门、carol 101 门，最下面一行「被挑战出局」 | 这个擂台开的是乐观模式：256 条公开向量只抽检 8 条。carol 交了一个只对了 217 条的作弊电路，碰巧躲过了抽检。但挑战期内任何人都能指出它错在哪一条——dave 一笔交易把它踢出榜单，拿走了它的保证金。 |
| 1:00–1:10 | carol 又混进来一枚（第 3 名、101 门）。点这一行的「挑战」，行内立刻出现红字「找到反例：向量 #… 不通过」 | 她又混进来一枚。我点一下挑战：浏览器自己算出反例，连上钱包就是一笔交易，她的保证金归我。 |
| 1:10–1:45 | 进入电路工作台，左边 HDL，右边版图实时变化；输入一行 `use FA = 0x…#2`，再用 for 循环拼出加法器；切到「擂台预检」页签，显示「通过全部 256 条向量，72 门，提交后预计排名 #2」 | 设计电路不用手连网表。在工作台写几行硬件描述，浏览器实时编译成 NAND 网表、画出版图、跑仿真。`use` 一行就能引用别人已经流片的组件，编译成 TapeOut 的 REF 门，不用重新烧晶体管。提交前先对擂台的链上向量做预检，告诉你能不能过、能排第几。 |
| 1:45–2:05 | 切到 AI 页签，输入「4 位比较器」，日志里一轮轮出现「编译通过 / 反例 / 门数下降」 | 不会写也没关系。告诉 AI 你要什么，它写代码，后端编译、跑向量、找反例，把错误喂回去，直到正确，再继续压门数。 |
| 2:05–2:30 | 打开组件库：FA9 带「擂台 #0 冠军」徽章、被引用 2 次；再回到 #1 擂台详情，显示 bob 作为上游作者分到 20% 奖金 | 每个冠军电路自动进入组件库。出题人可以拿出一部分奖金给上游：erin 用 bob 的全加器赢了 4 位加法器擂台，bob 什么都不用做，自动分到 20%。做通用组件第一次有了持续收入。 |
| 2:30–2:50 | 地址栏显示 `tape://…tape`，整站从 X Layer 链上加载；最后定格 Logo 和合约地址 | 整个前端存在 X Layer 的 DeWEB 上，没有服务器。协议按奖金抽 2.5% 的手续费。TapeArena：让链上芯片设计有需求、有排名、有回报。 |

备注：

- 1:00 那段不连钱包只会显示反例；想录完整交易，就在 OKX Wallet 里加自定义网络（RPC `http://127.0.0.1:8545`，链 ID 31337），用 `anvil_setBalance` 给自己的地址打点 OKB 再录。
- 演示数据每次都要新开 anvil 再跑 `scripts/demo.ts`（约 6 分钟），合约地址是固定的。
- 没有 AI 密钥时可以跳过 1:45–2:05，把时间分给工作台和组件库。
- 结尾的 `tape://` 画面用 TapeSend 或官方 Service Worker 网关打开链上网站录制。
