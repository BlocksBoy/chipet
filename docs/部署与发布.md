# 主网部署与 DeWEB 发布

所有上链操作都由你自己的钱包签名。脚本只读取 Foundry keystore（`--account`）或硬件钱包（`--ledger`），私钥不落盘、不进仓库。

## 0. 准备

- 钱包里有 OKB（X Layer 主网，链 ID 196）。部署合约不到 0.001 OKB；开容器 0.08 OKB；上传前端约 0.03 OKB（链上版约 5.5 MB、240 笔交易，按 0.02 gwei 估算；大头是钱包组件的 SDK）。
- 想建平台自己的处理器，还要 0.1 BEM 付工厂部署费（也可以直接用别人的公开处理器，跳过）。
- 把钱包导入 Foundry keystore（只需一次，会提示输入私钥和设置密码，由你本人在终端里操作）：
  ```bash
  cast wallet import tapearena --interactive
  cast wallet address --account tapearena   # 记下地址
  ```

## 1. 部署合约

```bash
cd contracts
# 可选：TREASURY=<收手续费地址> FEE_BPS=250 CREATE_CPU=1 CPU_NAME="TapeArena"
forge script script/Deploy.s.sol --rpc-url xlayer --broadcast --account tapearena --sender <你的地址>
cd .. && npx tsx scripts/sync-deployments.ts   # 把地址写进前端 deployments.json
```

部署完成后在 [OKLink](https://www.oklink.com/xlayer) 上能看到 `ComponentLibrary` 和 `TapeArena` 两个合约。如果需要开源验证，在上面的命令后加 `--verify --verifier oklink`（按 OKLink 文档配置 API key）。

## 2. 跑一个真实擂台（让评审能直接看到数据）

1. `npm run dev -w web`，右上角选 X Layer，连接 OKX Wallet。
2. 「发布擂台」：选一个示例（如 4 位加法器），点「生成向量」，流片参考电路，填奖金，发布。
3. 「工作台」里写一个更省门的版本 → 铸晶体管 → 流片 → 提交到这个擂台。
4. 截止 + 挑战期过后点「结算并发奖」。冠军电路自动进入组件库。

## 3. 发布到 DeWEB（链上网站）

链上网站挂在一枚**你持有的电路 NFT** 的容器下，名字是 `<电路ID>.<处理器编号>.tape`。随便用你流片过的一枚就行（比如第 2 步的参考电路）。

```bash
npm run build:deweb -w web                                   # 链上版：不连后端、不加载外部字体、只显示主网
npx tsx scripts/deweb-pack.ts <处理器地址> <电路ID>          # 切块 + 打印链上名字、持有人、待上传文件
cd contracts
forge script script/PublishSite.s.sol --rpc-url xlayer --broadcast --slow --account tapearena --sender <电路持有人地址>
```

`PublishSite` 会依次做：

1. 容器还没开通就调用 `open` 开通（0.08 OKB）。
2. 只上传哈希有变化的文件（24,000 字节一块），删掉旧版本留下的文件。
3. 把 `index.html` 设为单页应用的回退路径。
4. 容器没激活就用 `DomainBinding.bind` 激活名字，默认 12 个月（X Layer 当前月费为 0）。

以后改了前端，重新执行这三条命令即可，没变的文件不会重复付费。

访问方式：

- TapeSend 桌面版或 TapeKit 浏览器扩展里打开 `tape://<电路ID>.<处理器编号>.tape`；
- 官方 Service Worker 网关的子域名形式 `<电路ID>-<处理器编号>.<网关域名>`。

链上版的 AI 助手默认关闭：网关会拦截节点以外的链下请求。如果要开，构建时设置 `VITE_API_URL=https://你的后端`，并让用户在网关状态页放行这个域名。

## 钱包连接

前端用 RainbowKit 弹窗连接钱包，只列出浏览器里检测到的插件钱包：OKX Wallet、MetaMask、Rabby、Binance、Bitget、Coinbase、Trust、OneKey、TokenPocket，以及其他支持 EIP-6963 的插件。一个都没检测到时，点「连接钱包」会提示先安装钱包插件。

## 4. 后端（可选，只有 AI 助手需要）

```bash
AI_BASE_URL=https://api.openai.com/v1 AI_API_KEY=... AI_MODEL=gpt-4o-mini PORT=8787 npm start -w server
```

前端用 `VITE_API_URL` 指向它。其余功能（读擂台、预检、流片、提交、挑战、结算）全在浏览器里直接读写链，不依赖后端。
